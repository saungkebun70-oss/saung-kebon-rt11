# Portal Saung Kebun RT 11 RW 44

Sistem informasi dan manajemen warga RT 11 RW 44 berbasis web.

## Fitur
- Manajemen data warga
- Iuran dan keuangan
- Pengumuman dan kegiatan
- Pengaduan masyarakat
- Jadwal ronda
- Voting/jajak pendapat
- Dan lain-lain

## Cara Menggunakan
1. Buka website
2. Login dengan PIN default: **1234**
3. Pilih akun warga yang tersedia

## Teknologi
- HTML, CSS, JavaScript
- Firebase Realtime Database
- Responsive Design
